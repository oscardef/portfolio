## Overview

The site you're looking at. I wanted it to say something about me rather than list projects in a grid of cards, so it's organised around the route: every place I've lived, in order, and what I did in each.

## How It Works

- **Content:** each project and role is an MDX file whose frontmatter is validated with Zod at build time. A `chapter` field places it on the route, and a `kind` field groups it in the by-kind view.
- **Maps:** d3-geo projects Natural Earth land outlines at build time, using Equal Earth for the world and a conic projection for the Europe inset. The output is plain SVG path data, so no map library or map data reaches the browser.
- **The route animation:** each leg is an SVG path with `pathLength="1"`, drawn by animating its dash offset in CSS. Labels are HTML positioned over the SVG, so they stay readable at any screen size.
- **Sheets:** projects and roles open over the page through Next.js intercepting routes. The URL changes, the page underneath keeps its place, and visiting the URL directly renders a full page.
- **Rearranging:** switching between place and kind uses React's `<ViewTransition>`. Each item keeps the same name in both views, so the browser animates it from its old position to its new one.
- **Themes:** one set of colour tokens with light and dark values. Each stop on the route has its own hue, and the theme sets lightness and chroma in OKLCH.

## Stack

- **Next.js 16** with the App Router and static generation, on React 19
- **TypeScript** and **Tailwind CSS 4**
- **MDX** via next-mdx-remote, with Zod for frontmatter
- **d3-geo** and **world-atlas** for the maps
- **Vercel** for hosting
